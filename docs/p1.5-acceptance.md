# P1.5 验收清单 — 上帝视角观测面板

> P1.5 = "能选中 agent 看其状态、能暂停世界、能单步 tick"
> 估时 1 天。**上帝视角是核心体验**,每个阶段都必须能"看 agent 在想什么"。

## 必备验收项

### 输入
- [ ] `F1` —— 切换暂停/继续
- [ ] `F2` —— 暂停状态下推 1 tick(单步)
- [ ] `Tab` —— 切换当前观察的 agent(P1 阶段只有 player,循环无效)
- [ ] `` ` `` —— 切换调试 HUD 显隐(沿用 P1)
- [ ] `WASD/方向键` —— 移动玩家(沿用 P1)

### 视觉 — HUD 四段式面板
- [ ] 屏幕左上角深色半透明面板,4 行 Label
- [ ] **StatusLabel**: FPS / 当前 tick / RUNNING 或 PAUSED 状态
- [ ] **AgentLabel**: 当前选中 agent 的 `id / 坐标 / tile / 地形`(绿字)
- [ ] **ObservationLabel**: 当前 agent 视野内 tile 类型统计(蓝字,例如 `grass×42, tree×5, water×12`)
- [ ] **ActionLogLabel**: 当前 agent 最近 4 条行动(黄字,例如 `t12  move  → tile (32, 31)`)

### 行为
- [ ] 启动时 HUD 默认显示
- [ ] 玩家走动时:
  - `AgentLabel` 坐标和 tile 实时变化
  - `ObservationLabel` 周围 tile 统计随之变化(每 2 tick 刷新)
  - `ActionLogLabel` 不断有新的 `move` 记录
- [ ] 按 `F1`: `StatusLabel` 显示 `PAUSED`,玩家仍能移动但 tick 停止增长
- [ ] 暂停时按 `F2`: tick +1,`ActionLogLabel` 仍按真实 tick 标号
- [ ] 按 `Tab`: 选中 agent 在 `_agents` 数组中循环(P1 阶段 agent 列表只有 player,选中状态切换无视觉变化 — 这是设计预期,P5 多 agent 时自动生效)

### 工程
- [ ] `tests/test_smoke.gd` 跑通(16+ 项断言),覆盖:
  - World 程序生成、中心地形合法、角点不可走
  - 关键脚本可加载
  - Main.tscn 含 P1.5 节点结构
  - HUD/VBox 含 4 个 Label
  - Player.action_log 存在且 `_log_action` 正确
  - Player 提供 `get_observation` / `get_status_line` / `get_action_log_lines`
  - GameClock.paused 冻结 tick,`tick_once()` 强制推一 tick
- [ ] GDScript 静态检查无 Parse Error
