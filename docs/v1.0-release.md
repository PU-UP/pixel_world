# Pixel World v1.0 — 发布评审

> 首个大版本：P0–P7 核心闭环可玩，适合作为「可观测 AI 小镇」基线继续迭代。

## 版本范围

| 阶段 | 状态 | 交付物 |
|---|---|---|
| P0 工程基线 | ✅ | Godot 4 工程、GUT、AGENTS.md |
| P1 移动 + 相机 | ✅ | WASD / 点击移动、瓦片地图 |
| P1.5 观测 HUD | ✅ | F1 暂停、F2 单步、Tab 切换 |

| P5 多 agent + SAY | ✅ | 5 agent、并发 LLM、通信路由 |
| P6 规划 + 关系 | ✅ | 周期计划、关系持久化、F5 面板 |
| P7 世界物品 + 事件 | ✅ | PICK_UP/DROP/USE/GIVE/OBSERVE、小地图、区域事件 |

## 架构评审（通过）

- **硬边界清晰**：渲染/物理/寻路/原语执行由代码保证；LLM 仅输出合法 action。
- **观测优先**：每 tick 可看到观察、行动、决策；`data/logs/` 落 LLM 与决策行。
- **配置外置**：`config/*.yaml` 承载魔法数字，agent/世界/LLM 可调。
- **可扩展**：记忆 store、LLM 客户端接口稳定，P8 回放与 P4+ 向量检索有明确挂载点。

## 已知限制（v1.0 接受）

1. **美术**：占位色块地形，非正式 GBA tileset。
2. **原语**：`EMOTE` / `SLEEP` / `WAIT` 未实现。
3. **记忆检索**：关键词重叠近似，无 embedding。
4. **局内重置**：**Ctrl+R** 清空 tick、物品、记忆、关系并重新生成 agent（日志开新 session）。
5. **HUD**：逻辑分辨率 960×540，默认窗口 1600×900；观测面板已中文化。
6. **LLM 输出**：决策/对话内容仍为英文 prompt 驱动（agent 可能说英文）。

## 验收建议

1. 配置 `.env` 中 `MINIMAX_API_KEY`，F3 切到 agent 模式。
2. 运行 ~100 tick，确认 5 agent 移动、对话、拾取物品。
3. F4/F5/F6 面板数据随 Tab 切换更新。
4. 检查 `data/logs/{session}_summary.json` 含 token 统计。
