## 已知局限（见 `docs/agent-handoff.md`）

- **G 上帝视角** 仅去掉地形迷雾，**不**隐藏其他 agent 精灵（精灵在迷雾层之上始终绘制）。
- **灰色区域** 仅表示「曾探索的地形」，**不**隐藏曾在该处活动的同伴；与理想「角色视角」仍有差距。
- 探索图只记 **格子是否见过**，**不**快照地形；世界若日后可改动，灰色不会自动变「过时记忆」。
- **多 agent 扎堆可能物理卡死**：寻路不考虑其他 agent 占格，`CharacterBody2D` 碰撞 + `skip_while_walking` 可导致永久 `WALKING` 不再决策（见 `docs/agent-handoff.md` §P2.6）。
